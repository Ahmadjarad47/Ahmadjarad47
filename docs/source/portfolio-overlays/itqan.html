مفتوح المصدرقيد التطوير
الجهة مشروع مفتوح المصدر — تخطيط التصنيع الصناعي•الدور Full-Stack Developer — Backend & Frontend
الفكرة
المصنع الذي يبني منتجاً معقّداً يحتاج إجابات لآلاف القطع: ممّ تتكوّن؟ كم تكلّف؟ نصنعها أم نشتريها؟ من يورّدها؟ متى تُنتَج؟ وهل هي في المستودع؟ إتقان يربط كل ذلك عبر شجرة المنتج (BOM) في منصة واحدة.
ما تقدّمه المنصة
شجرة منتج بعمق غير محدود وتكلفة تراكمية فورية، قرار MAKE/BUY بالمفاضلة متعددة المعايير (MCDM)، دورة شراء بعشر مراحل مع عروض أسعار ومقارنة موردين، مسار تصنيع ومخطط جانت، مستودعات وحركات مخزون بتكلفة FIFO، مهام وأدوار وصلاحيات وحقول مخصّصة.
مساهمتي
بنيت الواجهة بـ Angular 22 (Signals وZoneless) بمعمارية نظيفة قابلة لاستبدال مصدر البيانات، والـ Backend بـ .NET 10 وفق Clean Architecture وCQRS (أكثر من 140 Endpoint في 8 وحدات) مع PostgreSQL وRedis وJWT، ونشر عبر Docker Compose وCaddy.
