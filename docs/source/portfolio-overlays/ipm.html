مفتوح المصدر
الجهة مشروع مفتوح المصدر — نظام داخلي للمؤسسات•الدور Full-Stack Developer — Backend & Frontend
الفكرة
مصدر واحد موثوق للمشاريع والمهام والمسؤوليات وقرارات الاعتماد. كل تغيير موثّق بمن نفّذه ومتى ومن اعتمده، دون فرض سير عمل أو حالات ثابتة: الأنواع والحقول والحالات وسلاسل الموافقة والأدوار تُهيّأ كلها من لوحة الإدارة.
ما تقدّمه المنصة
عناصر عمل بأنواع وحقول مخصّصة وعلاقات هرمية واعتماديات مع منع الحلقات؛ سير عمل لكل نوع ومشروع؛ محرك موافقات متسلسل مع التفويض ومنع الاعتماد الذاتي؛ صلاحيات ديناميكية على مستوى النظام والمشروع؛ ربط Git (GitHub / GitLab / Gitea) عبر Webhooks موقّعة؛ سجل تدقيق مقاوم للتلاعب بسلسلة Hash؛ إشعارات لحظية عبر SignalR وTelegram؛ لوحة مؤشرات وبحث شامل وتقارير Excel.
مساهمتي
بنيت الـ Backend بـ .NET 10 وفق Clean Architecture وCQRS (أكثر من 130 Endpoint) مع PostgreSQL وRedis وSignalR وOutbox للإشعارات، والواجهة بـ Angular 22 (Signals وZoneless) بالعربية RTL. أكثر من 400 اختبار Backend (وحدات، معمارية، تكامل عبر Testcontainers) وأكثر من 170 اختبار واجهة، مع تتبّع كل متطلب من وثيقة SRS إلى اختباراته، ونشر عبر Docker وNginx.
